# Bibliometric Good Practice — Notes

This file collects bibliometric good-practice guidance for the KTH Library team.
It is a starting point and will be expanded.

## Current guidance

- **Avoid the H-index** as a primary or standalone indicator. It conflates
  productivity and impact, is not comparable across fields or career lengths,
  and is sensitive to self-citation. If a user specifically requests it,
  provide it but flag these limitations alongside the number.
- **Do not use bibliometric indicators for small publication sets.** Citation-
  based indicators are unstable and can be misleading at low N (e.g. a single
  highly cited paper can dominate an average). Flag when a set is too small
  to support a reliable indicator rather than reporting one without
  qualification. (A specific N threshold has not yet been agreed — ask the
  user or use conservative judgement until one is set here.)
