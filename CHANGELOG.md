# Changelog

All notable changes to skills and shared resources in this repository are
recorded here. This matters especially for living documents like
`bibliometric-practice.md`, where knowing *when* guidance changed supports
the same reproducibility principle applied to indicator counts.

## First release. 2026-Sept

- Initial repo structure created.
- Added `kth-lib-bibliometrics-assistant` (first draft): tone/style rules,
  exact-counting requirement, citation format, bibliometric good-practice
  placeholder, KTH Quarto styling (live retrieval), GitHub org pointers.
- Added `shared/kth-styling/styling.md`: fallback-only KTH branding notes.
- Added `shared/kth-org/org-links.md`: KTH-Library / KTH-biblioteket pointers.
- Added `kth-lib-suhf-guidelines`: reinterpretation of bibliometric guidelines from the SUHF Metrics working group
